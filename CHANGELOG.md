# Changelog

## 0.2.0 (2026-09-28)

### Features

* the epistemic plane descriptor for the versum index: an nD system with its
  axes, a 5D binding, and `plane()` registered under the `loomground.planes`
  entry point, so indexed entries carry epistemic nD coordinates.
* the epistemic skill declares its own governance block (skill-governance-block
  v0.1).

### Dependencies

* requires `loomground-factual` 0.2.0.

## 0.1.0 (2026-08-07)


### Features

* initial public release of the loomground-epistemic plane — a know/believe modality over a proposition, an nD facet layered on the assertoric substrate (loomground-factual).
